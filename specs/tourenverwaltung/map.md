# Tourenverwaltung

## Umfang
- Alle Funktionen der App AndyTours nach dem Vorbild BikeXperience, soweit vom Benutzer ausgewählt (siehe `funktionsauswahl.md`)
- Einmalige Übernahme der BikeXperience-Altdaten in einem separaten Programm
- Erfassen, Auswerten und Importieren von Fahrradtouren; Verwaltung von Rädern und deren Wartung

## Nicht enthalten
- Mehrbenutzer-Verwaltung
- Altdaten-Import innerhalb der App
- Schwellwerte mit Farben
- Tourdetail: Puls-/Zonen-Auswertung, Rundenzeiten, Höhenprofil-Vergleich
- Karteikarten „Diagramme“, „Statistik“, „Kalender“, „Trainingsplan“, „Planung“
- Auskünfte: Jahresprognose, Top 50, Gewichtsverlauf, Ruhe-/Erholungspuls, Leistungs-/Trainingskontrolle, Ø-Geschwindigkeits-/Trittfrequenz-Diagramm, Temperatur, virtuelle Weltumrundung, Vergleich Aktivitäten/Kategorien
- Wartung: Kuchendiagramm, CSV-Export und -Import
- Equipment: Gewicht, Radumfang, Roll- und Luftwiderstandswerte, Kettenblätter und Ritzel, Bild
- Leistungsberechnung (Steig- und Gesamtleistung, Kalorien)
- Werkzeuge: Ritzelrechner, Pulsrechner, Marathonzeitenplaner
- Import von GPX- und TCX-Dateien
- Synchronisierung mit Garmin Connect (kein offizieller Zugang für Einzelnutzer)
- Anhänge einer Einheit öffnen (Aufzeichnung, Dokumentation)
- Werte einer Einheit aus ihrer Aufzeichnung neu übernehmen (der Garmin-Import übernimmt sie bereits beim Anlegen)
- Bildergalerie mit Geotagging (Fotos einer Einheit zuordnen und auf der Strecke verorten)

## Funktionen
In Umsetzungsreihenfolge.

- `datenordner-waehlen` — Der Benutzer wählt in den Einstellungen den Datenordner und kann ihn ändern; die Wahl bleibt beim nächsten Start erhalten (während der Entwicklung `AppDaten/`, sonst anfangs `Dokumente\AndyTours`).
  - Abhängig von: —
  - Status: done → [001-datenordner-waehlen](001-datenordner-waehlen/spec.md)
- `altdaten-umwandeln` — Ein separates Programm wandelt die BikeXperience-Daten aus `Daten/` einmalig in den Datenordner von AndyTours um und erstellt einen Bericht.
  - Abhängig von: `datenordner-waehlen`
  - Status: done → [002-altdaten-umwandeln](002-altdaten-umwandeln/spec.md)
- `hauptfenster-auswahl` — Das Hauptfenster bietet eine Jahres- und Aktivitätsauswahl und zeigt die Summen der Auswahl.
  - Abhängig von: `datenordner-waehlen`
  - Status: done → [003-hauptfenster-auswahl](003-hauptfenster-auswahl/spec.md)
- `datensicherung` — Die Datenbank wird automatisch in regelmäßigen Abständen gesichert.
  - Abhängig von: `datenordner-waehlen`
  - Status: done → [004-datensicherung](004-datensicherung/spec.md)
- `sicherung-wiederherstellen` — Der Benutzer kann eine Sicherung auswählen und den Datenbestand nach Rückfrage auf deren Stand zurücksetzen.
  - Abhängig von: `datensicherung`
  - Status: done → [005-sicherung-wiederherstellen](005-sicherung-wiederherstellen/spec.md)
- `einheiten-tabelle` — Alle Trainingseinheiten der Auswahl erscheinen in einer sortierbaren Tabelle mit Summenzeile und rot markierten Bestwerten.
  - Abhängig von: `hauptfenster-auswahl`
  - Status: done → [006-einheiten-tabelle](006-einheiten-tabelle/spec.md)
- `einheiten-filter` — Die Tabelle lässt sich nach Kategorie, Equipment, Trainingsbereich, Distanz, Höhenmetern und Name filtern.
  - Abhängig von: `einheiten-tabelle`
  - Status: done → [007-einheiten-filter](007-einheiten-filter/spec.md)
- `einheit-bearbeiten` — Der Benutzer kann eine Einheit neu anlegen, bearbeiten, kopieren und löschen.
  - Abhängig von: `einheiten-tabelle`
  - Status: done → [008-einheit-bearbeiten](008-einheit-bearbeiten/spec.md)
- `auswahllisten-verwalten` — Der Benutzer pflegt in den Einstellungen Auswahllisten mit festen Werten (zunächst die Trainingsbereiche), die in den Eingabefeldern angeboten werden.
  - Abhängig von: `einheit-bearbeiten`
  - Status: done → [009-auswahllisten-verwalten](009-auswahllisten-verwalten/spec.md)
- `aktivitaeten-kategorien-verwalten` — Der Benutzer kann Aktivitäten und Kategorien in den Einstellungen unter „Auswahllisten“ anlegen, umbenennen und löschen.
  - Abhängig von: `hauptfenster-auswahl`
  - Status: done → [010-aktivitaeten-kategorien-verwalten](010-aktivitaeten-kategorien-verwalten/spec.md)
- `equipments-verwalten` — Der Benutzer kann Räder und Ausrüstung in den Einstellungen unter „Auswahllisten“ anlegen, bearbeiten und als ausgemustert kennzeichnen.
  - Abhängig von: `hauptfenster-auswahl`
  - Status: done → [011-equipments-verwalten](011-equipments-verwalten/spec.md)
- `mehrfachauswahl-zuordnen` — Für mehrere markierte Einheiten kann der Benutzer auf einmal Kategorien zuordnen, die Aktivität wechseln oder das Equipment ändern.
  - Abhängig von: `einheiten-tabelle`, `aktivitaeten-kategorien-verwalten`, `equipments-verwalten`
  - Status: done → [012-mehrfachauswahl-zuordnen](012-mehrfachauswahl-zuordnen/spec.md)
- `persoenliche-daten` — Der Benutzer pflegt seine persönlichen Daten (Gewicht, Ruhe- und Maximalpuls, Heimatort).
  - Abhängig von: `hauptfenster-auswahl`
  - Status: done → [013-persoenliche-daten](013-persoenliche-daten/spec.md)
- `saisonziele` — Der Benutzer legt je Aktivität und Jahr Saisonziele für Kilometer, Höhenmeter und Anzahl fest.
  - Abhängig von: `aktivitaeten-kategorien-verwalten`
  - Status: done → [014-saisonziele](014-saisonziele/spec.md)
- `jahresfortschritt` — Die Ansicht „Aktuell“ zeigt den Jahresfortschritt bei km und hm gegenüber dem Saisonziel und die nötige Wochenleistung bis Saisonende.
  - Abhängig von: `saisonziele`
  - Status: done → [015-jahresfortschritt](015-jahresfortschritt/spec.md)
- `bestleistungen` — Die Ansicht „Aktuell“ zeigt die Bestleistungen mit dem jeweiligen Rekordjahr.
  - Abhängig von: `hauptfenster-auswahl`
  - Status: done → [016-bestleistungen](016-bestleistungen/spec.md)
- `mehrjahresdiagramm` — Die Ansicht „Aktuell“ zeigt ein Diagramm von km, hm und Fahrzeit über alle Jahre.
  - Abhängig von: `hauptfenster-auswahl`
  - Status: done → [015-jahresfortschritt](015-jahresfortschritt/spec.md) (in `jahresfortschritt` enthalten)
- `garmin-import` — Neue Touren vom angeschlossenen Garmin Edge 1040 werden eingelesen und als Einheiten angelegt; bereits vorhandene werden erkannt und übersprungen; die Gerätezuordnung der Equipments wird hier gepflegt.
  - Abhängig von: `einheit-bearbeiten`
  - Status: done → [017-garmin-import](017-garmin-import/spec.md)
- `hoehenprofil` — Zur gewählten Einheit wird das Höhenprofil der Aufzeichnung angezeigt.
  - Abhängig von: `einheiten-tabelle`
  - Status: done → [018-hoehenprofil](018-hoehenprofil/spec.md)
- `streckenkarte` — Zur gewählten Einheit wird die Strecke auf einer OpenStreetMap-Karte angezeigt.
  - Abhängig von: `einheiten-tabelle`
  - Status: done → [019-streckenkarte](019-streckenkarte/spec.md)
- `mehrtagestour` — Mehrere Einheiten lassen sich gemeinsam als Mehrtagestour auswerten (Summen, Höhenprofil, Karte).
  - Abhängig von: `hoehenprofil`, `streckenkarte`
  - Status: done → [020-mehrtagestour](020-mehrtagestour/spec.md)
- `wartung-erfassen` — Der Benutzer erfasst Wartungen mit Datum, Rad, Tätigkeit und Kommentar.
  - Abhängig von: `equipments-verwalten`
  - Status: done → [021-wartung-erfassen](021-wartung-erfassen/spec.md)
- `wartungsalarme` — Für ein Rad lässt sich ein Alarm nach einer bestimmten Kilometerzahl setzen, der bei Erreichen auffällig angezeigt wird.
  - Abhängig von: `wartung-erfassen`
  - Status: done → [022-wartungsalarme](022-wartungsalarme/spec.md)
- `teile-haltbarkeit` — Die App zeigt, wie viele Kilometer und Tage ein Teil zwischen zwei gleichartigen Wartungen gehalten hat; die Wartungstabelle zeigt dazu neben dem km-Stand die Kilometer seit der letzten gleichartigen Wartung desselben Rads (z. B. seit dem letzten Kettenwechsel).
  - Abhängig von: `wartung-erfassen`
  - Status: done → [023-teile-haltbarkeit](023-teile-haltbarkeit/spec.md)
- `wartung-equipment-auswahl` — Auf der Karteikarte „Wartung“ und in den Fenstern für Wartungen und Alarme erscheinen nur die Equipments, die zur gewählten Aktivität passen (z. B. keine Schuhe bei den Rädern); ausgemusterte Equipments erscheinen nicht.
  - Abhängig von: `wartungsalarme`
  - Status: done → [024-wartung-equipment-auswahl](024-wartung-equipment-auswahl/spec.md)
- `ausgemustert-kennzeichnen` — In allen Listen, Tabellen und Auswahlen steht hinter ausgemustertem Equipment der Zusatz „(ausgemustert)“.
  - Abhängig von: `wartung-equipment-auswahl`
  - Status: done → [025-ausgemustert-kennzeichnen](025-ausgemustert-kennzeichnen/spec.md)
- `suche` — Der Benutzer kann Einheiten über einen Suchbegriff in Name und Kommentar finden.
  - Abhängig von: `einheiten-tabelle`
  - Status: done → [026-suche](026-suche/spec.md)
- `equipment-einsatz` — Eine Auskunft zeigt die insgesamt gefahrenen Kilometer und Höhenmeter je Equipment.
  - Abhängig von: `equipments-verwalten`
  - Status: done → [027-equipment-einsatz](027-equipment-einsatz/spec.md)
- `gpx-export` — Der Track einer Einheit lässt sich als GPX-Datei exportieren.
  - Abhängig von: `streckenkarte`
  - Status: done → [028-gpx-export](028-gpx-export/spec.md)
- `track-bearbeiten` — Der Benutzer kann den Track einer Einheit kürzen, umkehren und glätten.
  - Abhängig von: `streckenkarte`
  - Status: done → [029-track-bearbeiten](029-track-bearbeiten/spec.md)
- `tourenplanung-karte` — Der Benutzer plant eine neue Strecke per Mausklick auf der Karte und speichert sie.
  - Abhängig von: `streckenkarte`
  - Status: done → [030-tourenplanung-karte](030-tourenplanung-karte/spec.md)
- `overlays` — Gespeicherte Strecken lassen sich als zusätzliche Ebene auf der Karte einblenden und in Ordnern verwalten.
  - Abhängig von: `streckenkarte`
  - Status: done → [031-overlays](031-overlays/spec.md)
- `courses-uebertragen` — Geplante oder gefahrene Strecken lassen sich als Course auf den Garmin Edge 1040 übertragen.
  - Abhängig von: `garmin-import`, `tourenplanung-karte`
  - Status: done → [032-courses-uebertragen](032-courses-uebertragen/spec.md)
