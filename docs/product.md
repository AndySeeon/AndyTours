# Produkt

## Was
- AndyTours: Windows-Desktop-App zur Verwaltung der eigenen Fahrradtouren
- Vorbild BikeXperience; umgesetzt werden nur die Funktionen, die der Benutzer tatsächlich nutzt
- Import neuer Touren vom Garmin Edge 1040
- Kein Altdaten-Import in der App; die vorhandenen Daten aus `Daten/` werden einmalig in das neue Format umgewandelt

## Zielgruppe
- Nur der Benutzer selbst (Einzelbenutzer)

## Ziele
- BikeXperience ablösen
- Alle vorhandenen Daten aus `Daten/` übernehmen
- Statistiken über die Jahre wie in der Ansicht „Aktuell“ von BikeXperience
- Wartung der Räder wie in BikeXperience
